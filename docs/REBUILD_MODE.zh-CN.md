# 重构已有应用

[English](REBUILD_MODE.md) | **简体中文**

Android 开发版新增与“从零创建”并列的 **重构已有应用** 模式。Living 绘制自定义界面，已安装的原应用执行实际业务。采用统一引擎和用户选取的适配数据，不承诺任意应用、任意功能均兼容。

Android 操作界面支持简体中文和英文；原应用内容和已经保存的组件名称保留原文。

## 使用流程

1. 在首页选择 **重构已有应用**，再选一个 Android 允许发现且带启动入口的应用。列出应用不代表已授权或已兼容。
2. 阅读无障碍说明，在系统设置手动开启服务，然后单独授权选中的原应用。程序不会自动开启权限。
3. 点击 **到原应用选取信息 / 动作**。底部操作条允许你自行浏览原应用，在目标页面点击 **选取当前页面**。
4. 添加文字信息、点击、输入或滚动动作。重复资源 ID 可以组成只读列表，或经明确选择的可点击列表。单个控件不能唯一定位时拒绝采用；缺少可用语义节点的页面暂不支持。
5. 修改名称、组件顺序、深浅色和布局密度。动作可以通过示范其他页面追加步骤，最多八步。一个流程最多包含一个当次输入，输入值不写入定义。
6. 启动自己的界面。原应用需位于首步所要求的页面。信息与列表来自当前已加载页面；匹配失败显示状态，不保留旧值。列表最多显示 40 项，不会自动加载屏幕外全部内容。
7. 点击动作后，每一步检查本地描述基线、来源身份、页面结构和唯一定位。Android 接受点击不代表业务成功。核对实际结果，可通过 **查看原应用 / 手动操作** 检查，再于一分钟内确认最后一次试用。此标记仅代表你在当前设备、当前定义及来源版本上确认过，不代表普遍兼容认证。
8. 可随时停止并回到 Living。运行时离开原应用或熄屏会结束会话。底部原应用操作条模式下，返回键操作原应用；完整自定义界面处理返回键退出。

## 本机能力边界

`RebuildSpec` 独立于记录类 AppSpec v1/v2，包含来源包名、安装版本号、签名证书指纹、名称/外观及最多 24 个组件。组件类型为 `read`、`list`、`action` 或 `input`。控件定位只包含资源 ID、类名、文字和内容说明。SHA-256 页面结构基线使用去重的资源/类/动作组合，允许列表行数变化并检测结构差异。它是兼容检查，不是完整的业务语义描述。

固定步骤仅支持控件点击、文字输入和向前滚动。没有坐标、脚本、任意 Intent、URL、Shell 命令、截图 API、网络控制监听器或远程执行。可点击列表会重新定位所选的可见文字，再在五层以内寻找最近的可点击父控件。重复匹配项禁用；不能点击无关应用的控件。

首版采用系统无障碍桥接，尚未实现 MediaSession 适配器、OCR、自动探索整个应用、条件分支、任意图形界面或不可见后台执行。密码节点、标记敏感的数据及识别出的敏感操作会阻止执行或交回原应用。关键词规则不是完整的金融/敏感行为分类器：此类业务应使用原应用。程序不绕过 Android、系统或原应用的保护。

页面遍历限制为 300 个可见节点、1,200 个访问节点及 40 层深度，截断后禁用动作。每步只有限等待目标页面，已被接受的点击不会自动重试。停止会取消后续步骤，但无法撤销原应用已完成的操作。

## 保存、恢复与更新

描述及追加式版本历史保存于本机私有 `living-rebuild.db`，独立于业务记录和原应用数据库。保存检查当前版本；编辑和恢复会产生新版本并清除试用标记。移除重构界面只删除 Living 的对应描述和历史。现有记录类全局备份 **不包含** 重构界面，设置页会明确提示；独立描述导入/导出留待后续实现。不声称数据库文件已加密。

原应用版本号变化后，运行被阻止。用户检查更新后可以接受新版本并重新试用，但定位和页面结构仍需匹配。签名证书变化要求重新建立关联。同版本的服务端界面调整由定位和页面结构检查发现，但不能保证识别全部语义变化。恢复历史界面不会降级或修改原应用。

## 可选自然语言编辑

复用现有可配置 Responses API，默认模型 `gpt-6.1-sol`、`store:false`，无静默切换。仅发送用户输入的需求和匿名组件编号/类型。不自动包含来源包名、控件定位、采集文字、组件名称、截图、账号内容或试用输入。用户也应避免自行在需求中填入私密页面内容。

模型只能对全部已有编号各使用一次，调整文案、顺序、名称、深浅色及密度。未知属性、丢失/重复组件及新增能力均被拒绝。生成结果先预览、再采用；迟到结果不能覆盖较新的定义。普通测试不调用付费 API。

## 验证及分发

实际检查与设备限制见[验证报告](VALIDATION.zh-CN.md)，固定版本参考见[开源审查](OPEN_SOURCE_REVIEW.zh-CN.md)。宿主测试使用合成包和窗口，不能作为 QQ 音乐兼容证据。真实 QQ 音乐的搜索 → 结果 → 播放仍需真机验收。

Google Play 要求无障碍说明和申报，并区分固定自动化与普通应用被禁止的自主规划/执行。这里 API 仅修改外观，运行采用固定且由用户明确触发的步骤；尚未取得商店审核结论。参见[官方政策](https://support.google.com/googleplay/android-developer/answer/10964491)。
