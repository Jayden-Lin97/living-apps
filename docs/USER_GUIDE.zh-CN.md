# 使用生长 0.2.0

[English](USER_GUIDE.md) | **简体中文**

## 安装与开始

安装 `dist/living-apps-0.2.0-debug.apk`，最低 Android 8.0。这是开发签名验证包，尚未上架商店。使用同一签名覆盖旧版可保留应用和记录；数据库会自动升级。

当前 Android 界面为中文，网页和文档提供独立的英文与中文版本。

第一次打开提供记账、喝水、阅读三个离线模板，没有虚构记录。点开即可新增记录，点击记录可修改或删除，统计在手机内计算。应用顶部铅笔进入编辑，历史图标查看版本。

## 创建与 AI 配置

设置中填写 API 网关、模型与自己的 Key。默认模型 `gpt-6.1-sol`；模型发现读取真实目录，不静默切换。Key 首次需手动填写，安装包不附带开发密钥，保存后由 Android Keystore 保护。

API 地址初始为空，请配置自己信任的 HTTPS 服务。HTTP 仅允许本机与安卓模拟器开发地址。

点击“创造一个应用”，例如“做一个跑步应用，记录日期、距离、耗时、心情和备注；默认打开记录页”。查看预览、试填并采用。支持记录、表单、清单、打卡与基本统计，不运行生成的网页或任意代码。

## 在应用画面中编辑

1. 点击铅笔，进入本机草稿；正式应用继续使用原版本。已有草稿会接着打开。
2. 在表单画面点输入项，或通过“记录项”选择隐藏字段、卡片、统计、应用和固定动作。轮廓与面板说明选中了什么。
3. “直接调整”可离线改名、上移下移、增字段和选项、设默认值、分组与隐藏；应用面板可改主题、图标、密度、首页、标题和统计。文字输入点“应用”才成为草稿修改。
4. 切到“AI 修改”提出要求，字段或固定动作可固定只改该对象。对话保留相关上下文，每次成功修改可撤销。需联网，发送需求、定义与相关对话，不自动发送记录或试用输入。
5. 面板可收起、半屏和展开。撤销重做在本机完成；返回先收起面板，再保存草稿退出。退出后回到使用页，保留搜索和滚动位置。
6. 点“试用”操作临时副本，新增、修改、删除只进入试用数据。可从本机复制最多 20 条记录试排版，不上传给模型。
7. 点“完成”检查差异、正式记录数量与兼容问题，再“保存新版本”；多次草稿修改形成一个正式版本，试用记录不带入正式库。

模型取消、失败或输出不支持能力时，输入与草稿保留。生成期间做了本地修改，结果留作待检查候选，不覆盖当前草稿。越界候选需明确允许本次范围才能合并，同属性冲突可选择保留本地值或采用候选值。

正式基线变化时，先“重新基于正式最新版合并”，合并前草稿留有快照。“更多”可恢复快照，普通操作可撤销重做。放弃草稿删除草稿、对话与试用副本，正式记录保留。

## 固定动作

整个应用的面板选择“固定动作 · 点击新增记录”，设置按钮名称和一条预设记录，日期可随点击当天变化。最多 6 个按钮，配置本身不执行。

先在试用中检查结果。保存版本后，在正式应用中点击才新增记录，页面提供撤销刚才记录的入口。记录后来已修改则阻止撤销，需到列表检查。动作不自动联网或后台执行。

## 数据转换与恢复

字段类型、数值换算和旧选项替换不走普通 AI 修改。先保存或放弃普通草稿，再到编辑器“更多 → 数据转换（独立流程）”。

- 文字可转数字、日期或开关，反向可转文字。日期须真实 ISO 日期；开关接受 true / false / 是 / 否。数字转文字关闭原累计引用与单位。
- 累计数字项可指定“新数值 = 原数值 × 倍率”和新单位。普通“首页与统计”单位设置只改文字。
- 选择字段须为每个旧选项指定目标；相同目标合并，未映射的历史值阻止转换。

先演算成功、失败、空值和缺项数量；失败不能部分提交。确认后再次检查基线与记录变化，保存并校验本机备份，再事务提交记录与新版本。默认值和固定动作预设同步转换，稳定 ID、其他字段和记录时间保留。上限为每应用 5000 条记录、5 MB 转换备份。

转换前的界面版本不能直接恢复，以免旧类型误读新数据。“更多 → 转换前备份”会校验并创建独立应用副本，保留当前应用和转换后新增记录。

## 本地观察与自主优化

“生长”页记录打开、保存、统计访问、校验错误及耗时，不记录输入正文。至少跨 2 天、打开 4 次才提出规则建议；保存达 6 次可建议快速入口，统计访问达到 6 次且显著多于保存可建议统计首页。

默认只建议。开启自动采用后，仅增加快速记录入口在允许列表中，每应用 24 小时最多一次。更多菜单可固定版本；有活动草稿时暂停自动采用，继续观察。后台使用 JobScheduler，目标间隔 6 小时，可能由系统延后，不调用模型 API。

“用 AI 深度分析改进”由用户主动发起，只附带定义和近 7 天聚合摘要。前后各至少 5 个有效耗时样本才显示观察对比，不当作因果改善证明。

## 全局备份

设置中导出明文 JSON，包含当前应用定义、记录与冻结状态；不含 Key、事件、历史版本、草稿、试用数据或转换前备份。需要导出转换前数据时，先创建转换前副本，再导出全局备份。选择可信的保存位置。

导入创建独立应用副本，不覆盖现有应用。上限 5 MB、50 个应用、每应用 5000 条 / 总计 20000 条记录；格式错误整次回滚。
